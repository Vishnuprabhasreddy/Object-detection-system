# 🎯 Object Detection System

A real-time object detection application that uses computer vision and deep learning to identify and locate multiple objects in images or live webcam video. The project leverages pre-trained deep learning models to perform accurate object recognition with bounding boxes and confidence scores.

---

## 📌 Project Overview

The Object Detection System is a computer vision project developed using Python and OpenCV. It detects and classifies objects in real time using a pre-trained deep learning model. The application processes video frames from a webcam or images, identifies objects, and displays labels with confidence scores.

This project demonstrates practical applications of computer vision, deep learning, and image processing for intelligent visual recognition systems.

---

## 🚀 Features

* 🎥 Real-time object detection using a webcam
* 📦 Detects multiple objects simultaneously
* 🏷️ Displays object labels with confidence scores
* 📍 Draws bounding boxes around detected objects
* ⚡ Fast and efficient image processing
* 🖼️ Supports both images and live video

---

## 🛠️ Technologies Used

* Python
* OpenCV
* NumPy
* TensorFlow / YOLO (depending on your implementation)
* COCO Dataset (Pre-trained Model)

---

## 📂 Project Workflow

1. Capture image or webcam video.
2. Load the pre-trained object detection model.
3. Process each frame for object detection.
4. Identify and classify detected objects.
5. Draw bounding boxes and labels.
6. Display the detection results in real time.

## ▶️ Installation

### Clone the repository

```bash
git clone https://github.com/Vishnuprabhasreddy/Object-Detection-System.git
```

### Navigate to the project folder

```bash
cd Object-Detection-System
```

### Install dependencies

```bash
pip install -r requirements.txt
```

